# Optical illusions audio bed

`ambient.mp3` is a local ffmpeg-synthesized ambient pad used by the `illusions-en` family.

- Source script: `scripts/illusions-en/gen-audio.mjs`.
- Content: generated pad/drone audio, loudness-normalized for the illusion videos.
- No downloaded samples, vocals, copyrighted recordings, or attribution requirements.
- Use only as a quiet background under optical illusion videos.
