# Motivation audio beds

These MP3 files are local ffmpeg-synthesized background beds for motivation packs.

- Source: generated from `ffmpeg` sine and noise filters in this repository session.
- No downloaded songs, samples, vocals, famous meme audio, copyrighted recordings, or attribution requirements.
- Intended use: low-volume motivational card videos with cinematic backgrounds.
- Keep these tracks instrumental, non-branded and quiet enough that overlaid text remains the focus.
