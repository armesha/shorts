# Islamic audio beds

These MP3 files are local ffmpeg synth beds for Islamic decks.

- Source script: `src/scripts/islamic-gen-audio.mjs`.
- Content: filtered noise only, such as wind/rain ambience.
- No downloaded samples, vocals, melodies, instruments, copyrighted music, or attribution requirements.
- Use these for Islamic shorts and long videos when a quiet non-musical background is needed; silence is also acceptable.
