# Music for long videos

Long-video packs use a separate music folder so their soundtrack is not mixed with short-form
backgrounds. The required rule for long compilations:

- one continuous music bed for the whole video;
- no per-scene music restarts;
- license-safe / no-copyright source only;
- keep the bed quiet under readable text;
- fade only at the beginning/end of the whole video.
