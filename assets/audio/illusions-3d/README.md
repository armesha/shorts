# 3D illusions audio bed

`ambient_drone.mp3` is a local ffmpeg-synthesized drone used by the `illusions-3d*` packs.

- Generator/pipeline notes: `docs/pack-generation.md`, section `Обмани свой мозг / Uberliste dein Gehirn`.
- Content: generated sine/drone layers with tremolo, echo, lowpass and loudness normalization.
- No downloaded samples, vocals, copyrighted recordings, or attribution requirements.
- Use only as a quiet background under optical/3D illusion videos.
