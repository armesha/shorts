# Музыка для генератора анекдотов

Сюда кладём **зацикливаемые, бесплатные (без авторских прав)** треки для роликов-анекдотов всех языков.

- Форматы: `.mp3`, `.m4a`, `.aac`, `.wav`, `.ogg`, `.opus`.
- Пайплайн берёт случайный трек и **зацикливает** его под длину ролика (5–6 сек) — короткие треки повторяются автоматически (`-stream_loop` в `src/video.ts`).
- Громкость/затухание в конце настраиваются в сборке видео.

## Где брать (Content-ID-безопасно, для монетизации)
- **YouTube Audio Library** → треки «no attribution required» (самые безопасные).
- **Pixabay Music**, **Mixkit** — без атрибуции (Pixabay изредка может дать claim).
