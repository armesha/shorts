# Стандарт карточек «Психология (DE)» (дека `psych`)

Цель: один зафиксированный формат, по которому можно **снаружи** генерировать карточки по любой
теме и через страницу **«Карточки»** залить их на сайт — без правок кода и без ручной доводки.
Всё, что проходит валидацию по этому стандарту, гарантированно рисуется шаблоном `templates/psych.html`
(авто-подгон шрифта сам впишет текст в кадр 1080×1920).

Источник правды в коде — `src/psych/schema.ts` (паттерны + лимиты). Валидатор
(`src/psych/cards-store.ts`) и панель-инструкция на странице используют именно его, поэтому документ
и проверка не расходятся.

## Формат карточки

```json
{
  "pattern": "numbered",
  "title_lines": ["3 stille Zeichen", "emotionaler Erschöpfung"],
  "items": [
    { "lead": "Reizbarkeit", "text": "Kleinigkeiten bringen Dich sofort auf die Palme." },
    { "lead": "Rückzug", "text": "Du sagst Treffen ab, obwohl Du Nähe brauchst." },
    { "lead": "Leere", "text": "Dinge, die früher Freude machten, lassen Dich kalt." }
  ],
  "outro": "Erschöpfung ist kein Versagen — sie ist ein Signal."
}
```

Загружать можно **одну карточку** (объект) или **массив** карточек.

### Общие правила (лимиты)

| Поле          | Правило |
|---------------|---------|
| `pattern`     | строго один из 8 паттернов (см. ниже) |
| `title_lines` | **ровно 2** короткие строки, каждая ≤ **48** символов (красный мазок рассчитан на две строки) |
| `items`       | **3–10** пунктов (рабочая дека — 7–10; авто-подгон ужимает шрифт до 22px) |
| `outro`       | необязательно, ≤ **150** символов (призыв/вывод под чертой) |

Язык контента — **немецкий**, обращение на «Du». Никакого markdown в значениях.

## 8 паттернов и поля `items`

| `pattern`        | поля пункта         | как рисуется |
|------------------|---------------------|--------------|
| `numbered`       | `lead`, `text`      | `N. **lead** — text` |
| `numbered_tight` | `lead`, `text`      | то же, плотнее (для 8–10 пунктов) |
| `bullet`         | `text`              | `• text` |
| `premium`        | `text`              | `• text` крупнее, обычно с `outro` |
| `bullet_color`   | `lead`, `text`      | `**lead** – text` (lead цветной) |
| `term`           | `term`, `val`       | `**term —** val` |
| `myth`           | `myth`, `real`      | `Mythos — … / Wahrheit — …` |
| `quote`          | `quote`, `author`   | `N. «quote» — author` |

Максимум на поле (символов): `lead` 48, `text` 170, `term` 52, `val` 170, `myth`/`real` 150,
`quote` 170, `author` 48. Лишние/неизвестные ключи в пункте отбрасываются при сохранении.

## Готовый промпт для генерации (подставь тему)

> Du bist Content-Designer für psychologische Kurzvideo-Karten (Deutsch, Du-Form).
> Erzeuge 10 Karten zum Thema **"<THEMA>"** als JSON-Array. Nur gültiges JSON, kein Markdown.
> Jede Karte: `pattern` (eines von numbered, numbered_tight, bullet, premium, bullet_color, term,
> myth, quote); `title_lines` = GENAU 2 Zeilen, je ≤ 48 Zeichen; `items` = 3–10 Objekte mit den
> Feldern je nach pattern; `outro` optional ≤ 150 Zeichen. Variiere die patterns über die Karten.

Кнопка **«Скопировать промпт для LLM»** на странице «Карточки» собирает этот промпт из актуальной
схемы автоматически.

## Как карточки попадают на сайт

1. Сгенерировал карточки по стандарту (любой LLM) → получил JSON-массив.
2. Страница **«Карточки»** → вставил JSON → **«Проверить и загрузить»**.
3. Сервер валидирует. Любая ошибка формата → **ничего не сохраняется**, показывает список что починить
   (всё-или-ничего).
4. Валидные карточки дозаписываются в `data/psych/cards.json` (помечаются `addedAt`,
   `source:"upload"`), кэш деки сбрасывается — карточки **сразу доступны** в Студии/генерации
   **без перезапуска сервера** (роуты уже подняты).
5. Лента «Недавно загруженные» (с пагинацией) показывает добавленное; «Предпросмотр» рисует реальный
   кадр 1080×1920.

> ⚠️ Первый запуск после деплоя: новые серверные роуты (`/api/psych/cards*`) поднимаются только при
> старте сервера. Если страница пишет «бэкенд ещё не знает про этот раздел» — нужен один перезапуск.

## Расширение на другие темы/языки

Сейчас включена только дека `psych` (немецкая психология). Поле «язык/дека» в форме заблокировано
на `psych`. Чтобы открыть тот же конвейер для новой деки — добавить её в `src/psych/schema.ts`-аналог
и снять блокировку селектора (отдельная задача).
