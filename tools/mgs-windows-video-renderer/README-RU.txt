MGS SHORTS RENDERER ДЛЯ WINDOWS 10/11
====================================

Запуск
------
1. Полностью распакуйте ZIP-архив в обычную папку.
2. Положите картинки в папку «КАРТИНКИ». Для двух каналов можно создать
   внутри неё две подпапки с названиями каналов.
3. Дважды нажмите «1 - ЗАПУСТИТЬ ПРОГРАММУ.bat».
4. Нажмите «НАЧАТЬ МОНТАЖ».

Готовые ролики появятся в папке «ГОТОВЫЕ ВИДЕО». Если картинки разложены
по подпапкам каналов, программа сохранит ту же структуру для готовых роликов.
Поля выбора папок уже заполнены автоматически, но при желании их можно менять.

Ничего устанавливать, вводить в командной строке или настраивать в Windows
не нужно. Файл START-MGS-RENDERER.bat — запасной запуск с видимой консолью;
он нужен только для диагностики, если основной запуск не открыл окно.

Режимы
------
«Каждая картинка — отдельный ролик»
  Каждая картинка из выбранной папки и её подпапок становится отдельным роликом.
  Имя MP4 берётся из имени картинки.

«Каждая подпапка — один ролик»
  Каждая подпапка становится одним роликом. Картинки внутри идут по именам:
  01.jpg, 02.jpg, 03.jpg и так далее. Картинки непосредственно в главной
  выбранной папке также собираются в отдельный ролик.

Настройки
---------
«Секунд на картинку» — сколько секунд показывать картинку.
«Плавный переход» — плавное затемнение. Значение 0 отключает его.
«Качество» — 18 даёт лучшее качество и большой файл, 30 — меньший файл.
«Заполнить кадр» — заполнить весь кадр с обрезкой краёв. Без галочки картинка
помещается целиком, а свободные поля становятся чёрными.
«Не пересобирать готовые MP4» — пропускать уже существующие файлы.

Формат результата
-----------------
1080 x 1920, H.264, 30 кадров/с, AAC 48 кГц, MP4, fast start.
Если музыка не выбрана, в ролик добавляется тихая звуковая дорожка.
Длительность автоматически уменьшается до 59 секунд, если в папке много
картинок. При количестве более 118 картинок папку нужно разделить.

Поддерживаемые картинки: JPG, JPEG, PNG, WebP, BMP.
Поддерживаемая музыка: MP3, WAV, M4A, AAC, OGG, Opus.

Важно
-----
- Программа работает локально и ничего не отправляет в интернет.
- Исходные картинки не изменяются и не удаляются.
- Готовые ролики можно вручную загрузить в библиотеку канала Shareboard.
- При предупреждении Windows SmartScreen нажмите «Подробнее» и запускайте
  только архив, полученный непосредственно от владельца проекта.
- Если PowerShell заблокирован корпоративной политикой Windows, передайте
  текст ошибки владельцу проекта.
