# Changelog

Заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/).

## [Unreleased] — 2026-06-13

### Добавлено
- **Мультиязычные паки**: Русские · Deutsche Witze · Barzellette Italiane · Blagues françaises
  (реестр `src/anecdotes/decks.ts`, своё оформление и YouTube-теги на каждый язык).
- **Выбор пака в Студии** — запоминается между визитами.
- **Пакетная генерация** «+5 / +10» роликов в библиотеку канала.
- **Без повторов**: каждый анекдот используется один раз (учёт использованных).
- **Очередь «один раз»**: ролик выкладывается ровно один раз и удаляется; планировщик берёт
  из библиотеки канала; пусто → по расписанию ничего не постит.
- **Превью по клику**: окно с видео, полным текстом и кнопкой «Выложить».
- **Ссылка на YouTube** баннером сразу после выкладки + ссылка на канал рядом с подключённым.
- **Пагинация и сортировка** в библиотеке.
- **Жёсткая языковая защита**: канал работает только со своим языком — чужой не сохранить и не выложить.
- **Кроссплатформенность** (Windows/macOS/Linux): автопоиск Chrome/Edge, Vite IPv4+IPv6,
  прокси `127.0.0.1`, запуск одной командой `npm start`.
- **CHANGELOG.md** + правило вести его и коммитить/пушить после каждой фичи.

### Изменено
- Планировщик: ротация/автогенерация → очередь «один раз».
- Текст ролика центрируется по вертикали (заполняет кадр, меньше пустоты); подобраны мин. длины по языкам.
- Время — 24-часовой ввод; интерфейс и ответы — на русском.
- README упрощён для не-программиста.

### Убрано
- Выбор даты у каждого ролика (дублировал расписание канала).
- Старые Python-эксперименты (в репозиторий не попадают).

### Исправлено
- Итальянский: чистка mojibake и форумного «чатера»; французский: фильтр взрослого контента.
- Плеер музыки (прокси `/audio`), отображение ближайшего запуска и др.
