# Changelog

Коротко о публичных изменениях. Один день — одна версия.

## [0.139] — 2026-07-09

### Добавлено
- **Аудио** — русская мимика говорящей головы теперь строится локальной MFA-моделью по точным таймингам фонем готового WAV.
- **Аудио** — новый оригинальный 3D-персонаж «Витёк» с живой мимикой, пятью формами губ и управлением камерой мышью.
- **Аудио** — CC0-персонаж «Майя» в режиме говорящей головы: крупный план, 52 формы лица и отдельные речевые положения губ.
- **Creator** — панель «Фон»: фон любого шаблона пака меняется в пару кликов (галерея, свои загрузки).
- **Creator** — лента шаблонов в редакторе: видно, какой шаблон правишь; лишний шаблон можно удалить.
- **Creator** — карточки: дублирование, перенос на другой шаблон, поиск; превью каждой карточки — на фоне её шаблона.
- **Creator** — видео: стрелки навигации по карточкам и прослушивание озвучки до сборки ролика.
- **Creator** — кнопка «В приложение» в шапке студии.

### Изменено
- **Мобильная навигация** — в нижней панели оставлены только «Каналы», «Статистика» и «История».

### Исправлено
- **Каналы** — выбор пака для конкретного слота сохраняется сразу и больше не откатывается после сохранения настроек.
- **Статистика** — в «Общем топе роликов» ссылка канала теперь открывает канал на YouTube.
- **Creator** — правка дизайна больше не стирает остальные шаблоны пака и их фоны.
- **Creator** — созданный пак любого типа сразу виден в «Моих паках» (раньше «терялись» не-шуточные).
- **Creator** — студия стала удобнее на телефонах: лента шаблонов, компактные формы и превью.

### Удалено
- **Бронирование мест** — старая страница `/cars1` снята с публикации; актуальная страница остаётся на `/cars2`.

## [0.138] — 2026-07-08

### Изменено
- **Telegram-бот** — дайджест статистики стал намного короче и аккуратнее: только период, публикации, YouTube за период, общие итоги и красивая ссылка.

## [0.137] — 2026-07-07

### Добавлено
- **Статистика** — графики по дням (просмотры и часы) внутри «Подробной аналитики» канала.
- **Статистика** — панель «Общий топ роликов» можно скрыть и вернуть, выбор запоминается.

### Изменено
- **Статистика** — итоги обновления показываются всплывающими уведомлениями справа снизу.
- **Статистика** — название канала стало ссылкой на канал в YouTube.
- Рабочая область страниц стала шире — меньше пустых полей по бокам.
- **Статистика** — новый визуал: KPI-плитки со спарклайнами, редизайн графиков, полосы источников, топ роликов с обложками.
- **Статистика** — ширину «график / топ роликов» теперь меняет перетаскиваемый мышкой разделитель.
- **Статистика** — вкладки источников: основная Analytics и отдельная «Data API» с публичными счётчиками.
- **Статистика** — метрики на карточках в отдельных плашках с обводкой, цифры не сливаются.
- **Telegram-бот** — новый визуал экранов: Analytics и Data API разделены, аккуратные кнопки и навигация.
- **Telegram Mini App** — визуальная статистика: график просмотров за 30 дней с выбором дня, метрики и спарклайны каналов.

## [0.135] — 2026-07-01

### Добавлено
- **Creator** — карточки можно загружать пачкой из текста или файла, сразу 10–100 штук.
- **Creator** — готовое «задание для ИИ» и пример файла для быстрого набора карточек.
- **Creator** — правка, удаление и превью-рендер каждой карточки проекта.
- **Creator** — вкладка «Видео»: MP4/PNG по карточке, ZIP по паку и галерея готовых файлов.

### Изменено
- **Creator** — страница перестроена вокруг проектов: шаблон, карточки и видео в одном месте.

## [0.134] — 2026-06-29

### Добавлено
- **Тематические блоки** — каналы показывают предупреждение, если отдельный источник пустой или больше не пополняется, но публикация продолжит брать другие доступные паки.
- **Каналы** — в обычном списке те же предупреждения показываются прямо на паках канала.

### Изменено
- **Тематические блоки** — языковые колонки показываются только там, где у armen уже есть каналы.
- **Тематические блоки** — добивка запаса учитывает пустые источники в слотах, даже если общий запас канала уже достаточный.
- **Тематические блоки** — подпись страницы показывает только активные языки armen.
- **Каналы armen** — visual/optical-паки скрыты из выбора источников и запрещены серверными проверками; для других пользователей каталог не менялся.
- **Студия armen** — source picker и список паков больше не предлагают retired/MGS-only источники; старый локальный выбор автоматически переключается на доступный пак.
