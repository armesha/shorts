# Changelog

Заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/).

## [Unreleased] — 2026-06-13

### Добавлено
- **Статистика каналов (новая вкладка)** — у каждого пользователя: подписчики, просмотры и число
  видео по каждому каналу. Кнопка «Обновить данные» опрашивает YouTube (**тот же доступ, что и
  загрузка — переподключать каналы не нужно**), сохраняет снимок и показывает **+/− изменение** с
  прошлого раза; по накопленным снимкам строится **график динамики** (Recharts). Админ
  переключателем «Все каналы» видит статистику всех пользователей. Данные берутся у Google —
  стороннего сервиса не требуется.
- **Мультиязычные паки**: Русские · Deutsche Witze · Barzellette Italiane · Blagues françaises
  (реестр `src/anecdotes/decks.ts`, своё оформление и YouTube-теги на каждый язык).
- **Заголовки через Haiku** для DE/FR/IT; итальянский расширен 2-й группой Usenet (umorismo) и
  очищен Haiku (→ 2163 шутки). Немецкий — короткие склеены **по 2 в карточку** (5290 → 2645),
  заполняют кадр без ИИ. Готовые паки: RU 275 · DE 2645 (пары) · IT 2163 · FR 1074.
- **Народные лайфхаки (новая дека `tips`)**: 979 русских советов, сгенерированы **через Haiku**
  и разложены **по 10 профессиям** (повар · автомеханик · пожарный · юрист · бухгалтер · учитель ·
  программист · строитель · полицейский · парикмахер) — каждая профессия даёт советы по своей теме.
  Свой шаблон `templates/lifehack.html`: заголовок в красной плашке, текст обтекает фигуру
  профессионала (`shape-outside`), фон по профессии из `assets/backgrounds/lifehacks/`.
  Сборка `src/anecdotes/build-tips.ts` (длина 310–479, медиана 377). Работают те же правила:
  без повторов (один раз использовал → из пака) и очередь «выложился один раз».
- **Смена пароля** — пользователь сам меняет свой пароль (Настройки → «Смена пароля»), чтобы его
  не знал даже администратор, выдавший первый. Роут `POST /api/auth/change-password` (проверка
  текущего пароля, новый ≥6 символов и отличный от старого; блокировка сбрасывается).
- **Выбор пака в Студии** — запоминается между визитами.
- **Пакетная генерация** «+5 / +10» роликов в библиотеку канала (админу — ещё «+20»).
- **Без повторов**: каждый анекдот используется один раз (учёт использованных).
- **Очередь «один раз»**: ролик выкладывается ровно один раз и удаляется; планировщик берёт
  из библиотеки канала; пусто → по расписанию ничего не постит.
- **Превью по клику**: окно с видео, полным текстом и кнопкой «Выложить».
- **Ссылка на YouTube** баннером сразу после выкладки + ссылка на канал рядом с подключённым.
- **Пагинация и сортировка** в библиотеке.
- **Жёсткая языковая защита**: канал работает только со своим языком — чужой не сохранить и не выложить.
- **Кроссплатформенность** (Windows/macOS/Linux): автопоиск Chrome/Edge, Vite IPv4+IPv6,
  прокси `127.0.0.1`, запуск одной командой `npm start`.
- **CHANGELOG.md** + правило вести его и коммитить/пушить после каждой фичи.
- **Авторизация (вход в панель)** — вся панель и API закрыты логином. Пароли хранятся
  scrypt-хэшем (без плейнтекста), сессия — httpOnly-кука на 30 дней. Защита от перебора:
  **блокировка аккаунта после 10 неудачных попыток** на 15 минут. Пользователи заводятся
  из `.env` (`ADMIN_USERNAME`/`ADMIN_PASSWORD`, `SEED_USERS="имя:пароль,…"`), роли admin/user.
  Это **Этап 1**; изоляция данных по пользователям (свои каналы/ключ, общие анекдоты) — Этап 2.
- **Мультиюзер (изоляция данных, Этап 2)** — каждый юзер видит и трогает только СВОИ каналы,
  библиотеку и историю; чужое = 404. Свой **Google-ключ на пользователя** (загрузка
  `client_secret.json` в Настройках), OAuth-подключение и автопостинг используют ключ владельца
  канала. Учёт «использованных» анекдотов — на пользователя (общий пул, свой счётчик). Админ
  создаёт пользователей кнопкой (Настройки → Пользователи). Старт без глобального ключа больше
  не падает — это нормальный режим мультиюзера.
- **Прод-режим (один URL)** — Fastify отдаёт собранный фронт (`web/dist`) с того же порта, что и API,
  с SPA-fallback. Готово к хостингу/туннелю одной точкой входа. В dev по-прежнему `npm run web`.
- **`npm run share`** — публичная HTTPS-ссылка через бесплатный **cloudflared**-туннель (без домена и
  без аккаунта). `scripts/tunnel.mjs` сам качает cloudflared (кросс-платформенно, в `node_modules/.cache`),
  собирает фронт, поднимает сервер и печатает ссылку для друзей.
- **`scripts/set-password.ts`** — сброс пароля пользователя прямо в БД (CLI), пока нет UI смены пароля:
  `node --import tsx --experimental-sqlite scripts/set-password.ts <логин> <пароль>`.

### Изменено
- Планировщик: ротация/автогенерация → очередь «один раз».
- Текст ролика центрируется по вертикали (заполняет кадр, меньше пустоты); подобраны мин. длины по языкам.
- Время — 24-часовой ввод; интерфейс и ответы — на русском.
- README упрощён для не-программиста.
- Вкладки «Обзор» и «Каналы» объединены в одну («Каналы» — обзор-статистика + список каналов).

### Убрано
- Выбор даты у каждого ролика (дублировал расписание канала).
- Старые Python-эксперименты (в репозиторий не попадают).

### Исправлено
- Итальянский: чистка mojibake и форумного «чатера»; французский: фильтр взрослого контента.
- Плеер музыки (прокси `/audio`), отображение ближайшего запуска и др.
