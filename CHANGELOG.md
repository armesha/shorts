# Changelog

Что нового в проекте. Коротко — по одному пункту на изменение.

## [0.105] — 2026-06-16

### Добавлено
- **Язык интерфейса** — переключатель «Русский / English» в боковом меню; вся панель доступна на двух языках.

### Исправлено
- **Понятные причины ошибки выкладки** — в истории отдельно видно: лимит загрузок канала, исчерпанную квоту API или слишком частые запросы.

## [0.104] — 2026-06-16

### Добавлено
- **Удаление своего пака** — владелец удаляет пак целиком прямо на «Карточках», с подтверждением.
- **Редактирование своего пака** — создатель пака меняет его имя и язык прямо на «Карточках» (другим пак доступен только для генерации).

### Изменено
- **«За раз» до 50 роликов** (было 25) и не больше, чем осталось свободных карточек в паке.

## [0.103] — 2026-06-15

### Добавлено
- **Вход через Telegram** — привяжи Telegram в Настройках и входи в один клик.
- **Восстановление пароля через Telegram** — бот присылает одноразовый код для сброса.
- **Русские анекдоты на тематических фонах** — кухня/баня/поезд и др., текст ложится в «лист» сцены; +250 новых карточек (пары по 350–450).
- **Пак как источник канала** — выбери свой пак в настройках канала и генерируй ролики прямо из него.
- **Язык канала** — отдельное поле; пак другого языка не даст сгенерировать (мягкое предупреждение).
- **Аватарки каналов** — у каждого канала своя картинка (100 на выбор + можно загрузить своё фото); по умолчанию случайная. Видна в списке каналов, истории и статистике.
- **Аналитика по своим каналам** на «Статистике» — активность публикаций (опубликовано / запланировано / ошибки + график по дням), только по вашим каналам.

### Изменено
- **Аккуратнее панель генерации в библиотеке** — кнопка «Сгенерировать» не съезжает, адаптивно под узкие экраны.
- **Удобный просмотр библиотеки канала** — ролики сеткой постеров; клик открывает видео в своём плеере (перемотка, звук, повтор, на весь экран).
- **Доступность и полировка** — видимый фокус с клавиатуры на всём интерфейсе, поддержка «уменьшить движение», единообразные заголовки, смена пароля по Enter, аккуратные даты/тексты.
- **Единое обращение на «вы»** во всех подсказках и кнопках (было вперемешку).
- **Окна подтверждения внутри приложения** — удаление канала/ролика/ключа спрашивает в аккуратном окне (не сером браузерном); ошибки показываются всплывающим сообщением, а не системным alert.

## [0.102] — 2026-06-14

### Добавлено
- **Свои паки на «Паках»** — кастомные паки видны в обзоре, можно удалить свой.
- **Причина ошибки в «Истории»** — у неудачных автозагрузок (failed) видно, что пошло не так (квота, токен, нет канала и т.п.).
- **Сортировка по остатку видео** на «Каналах» (кнопка ↑/↓) + предупреждение, когда у канала меньше дня роликов (не спамит, само исчезает).
- **Генерация в фоне** — прогресс висит уведомлением в правом нижнем углу; можно уходить на другие страницы.
- **Расписание «раз в день»** — задаёшь число публикаций, время раскидывается равномерно со случайным сдвигом (каналы не постят одновременно).
- **Редактор шаблонов** (эксперимент) — конструктор карточек 1080×1920 с экспортом в JSON.

### Исправлено
- **Падение выгрузки на `<`/`>`** — символы в title/описании меняются на `‹`/`›` (YouTube отбивал `invalidDescription`).

## [0.101] — 2026-06-14

### Добавлено
- **4 языка анекдотов** — RU / DE / IT / FR, у каждого своё оформление и теги.
- **Лайфхаки по профессиям** — русская и немецкая колоды советов.
- **Исламская колода** — 500 арабских карточек (Коран · хадисы · дуа), свой природный эмбиент.
- **Карточки психологии** — отдельная страница, вставка по JSON.
- **Пакетная генерация** — сразу несколько роликов в библиотеку, с остановкой.
- **Студия** запоминает выбранную колоду.
- **Без повторов** — каждый анекдот идёт в дело один раз; очередь «один раз» (пусто → ничего не постится).
- **Превью по клику** + **ссылка на YouTube** баннером после публикации; пагинация и сортировка в библиотеке.
- **Статистика каналов** — подписчики / просмотры / видео с динамикой (из YouTube, без переподключения).
- **«Обновления»** — этот список изменений; **«Паки»** — остаток карточек по каждому паку.
- **Видео в сутки** — плитка на «Каналах».
- **Лимит 100 публикаций в сутки** на пользователя.
- **Вход по логину** + защита от перебора; **смена пароля** каждым; **личные данные** изолированы; **публичная ссылка** одной командой.

### Изменено
- Статистика: сортировка, фильтры, пагинация, запоминание выбранного.
- 24-часовое время везде; интерфейс на русском.
- «Обзор» и «Каналы» — одна вкладка; текст ролика крупнее.

### Убрано
- Выбор даты у ролика (дублировал расписание канала).

### Исправлено
- Полировка интерфейса, адаптивное меню на телефонах, чистка контента (IT/FR), ввод времени строго 24ч.
