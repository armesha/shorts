# Источник итальянских анекдотов / Italian jokes source

Собрано из **UsenetArchiveIT** — архив итальянского Usenet, группа `italia.bologna.barzellette`:
https://huggingface.co/datasets/mrinaldi/UsenetArchiveIT

Обработка: NDJSON → отброшены ответы (`Re:`), подписи, цитаты, мусорная кодировка →
фикс mojibake → фильтр мата/NSFW/слюров и форумного чатера → дедуп → длина 120–400.

⚠️ **Лицензия / риск:** зеркало датасета (`mii-community/UsenetArchiveIT-conversations`) —
Apache-2.0, но авторские права на сами шутки остаются за авторами постов Usenet
(короткие народные шутки). Использование принято на свой риск (по решению владельца проекта).

⚠️ **Качество:** Usenet не модерируется — часть постов всё ещё «форумный чатер», а не шутки.
Рекомендуется семантическая чистка на этапе Haiku-заголовков (LLM отсеивает не-шутки).
